## Pull requests

- When the change has a visible surface, add a few screenshots, up to 3, that capture as much of it as possible. Upload them as GitHub attachments, as the PR web editor does when you drop an image, and embed the resulting `github.com/user-attachments` URLs. Never commit screenshots to a branch.
- Describe the user-facing features as a bulleted list.
- Describe the technical changes as a bulleted list.
- End with a timeline summary of the agent prompts used throughout the task: in broad strokes, the initial design and how it evolved, not the full prompts.
